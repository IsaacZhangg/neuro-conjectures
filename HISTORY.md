# History

## 2026-11-25: Start the collection

Collection design, verification guide, result template and candidate list
drafted. First worked example: a finite-size simulation of Hopfield network
storage capacity (replication).

## 2026-11-25: Pre-register the power-law eigenspectrum test

Claim, sources and analysis plan for target 2 (Stringer et al. 2019, α ≈ 1)
committed before any data were read. The original data are not reachable from
the cloud environment, so the test uses Allen Brain Observatory two-photon and
Neuropixels sessions with a finite-image forward model.
## 2026-11-25: Park the power-law eigenspectrum test

Parked before any real data were analysed, because the project now focuses on
unsolved conjectures rather than re-testing published findings. A pre-data
amendment and partial synthetic validation are recorded in the result's
METHODS.md and STATUS.md.
