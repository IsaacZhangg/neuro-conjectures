# Sources

Checked 2026-11-25.

## Primary

- D. J. Amit, H. Gutfreund, H. Sompolinsky. "Storing infinite numbers of
  patterns in a spin-glass model of neural networks." Physical Review Letters
  55(14):1530–1533 (1985). doi:10.1103/PhysRevLett.55.1530.
  - Abstract: associative memory for α < α_c, with α_c ≥ 0.14.
  - Main text: α_c = 0.138 in the replica-symmetric solution; table of error
    percentages by α (0.1% at α = 0.10, jumping near α = 0.14); remark that
    replica-symmetry breaking may raise α_c slightly.
